# 山西古建地图项目需求文档

## 1. 项目背景与目标
- **项目背景**：现有“订阅管理”项目需重建为聚焦山西省古建筑资源的地图信息应用，服务文化旅游、研究人员与公众。
- **产品愿景**：提供可视化、互动式的古建分布地图，整合文物信息、图片资料与路线规划，提升用户对山西古建文化的认知与访问体验。
- **成功标准**：
  - 完成覆盖山西主要古建遗址的基础数据录入。
  - 提供稳定的地图交互（缩放、拖拽、定位）与信息展示。
  - 用户可根据不同维度查询、筛选并收藏关注的古建。
  - 支持移动端友好访问，主要功能响应时间 < 2s。

## 2. 用户画像与使用场景
### 2.1 用户角色
1. **游客 / 古建爱好者**：获取景点信息、规划路线。
2. **文化研究者**：检索特定朝代、建筑类型，查看详细资料。
3. **文旅管理者**：关注古建保护状态、客流热点。

### 2.2 核心使用场景
- 在地图上浏览山西古建分布，点击标记查看详情。
- 搜索特定城市/县域或古建名称，快速定位。
- 根据朝代、建筑类型、保护级别筛选古建列表。
- 查看古建图文详情、历史简介、开放时间、交通信息。
- 添加到收藏夹，生成个性化参访清单。
- 根据地理位置规划参观路线（自驾/公交）。

## 3. 功能需求
### 3.1 地图展示
- 基于可交互地图（平移、缩放、定位）。
- 标注古建位置点，支持热力层或聚合展示。
- 支持定位到用户当前位置、按行政区边界导航。

### 3.2 数据浏览与检索
- 全局搜索（名称、别名、所在地）。
- 高级筛选：朝代、建筑类型（寺庙、塔、戏台等）、保护级别（全国重点、省级等）、开放状态。
- 列表视图与卡片视图切换，支持排序（距离、知名度、更新时间）。

### 3.3 古建详情
- 展示基本信息：名称、地址、朝代、类型、保护级别、开放信息。
- 图集浏览（支持主图与缩略图预览）。
- 历史沿革、建筑特色、修缮记录。
- 实用信息：门票、开放时间、交通方式、周边推荐。
- 可分享链接或生成二维码。

### 3.4 路线与行程
- 与地图联动生成起点到古建的导航链接（调用第三方地图）。
- 收藏夹：添加/移除收藏，排序，导出行程（PDF/分享）。
- 推荐线路：基于标签组合或地理邻近度，推荐一日游、多日游路线。

### 3.5 管理后台（后续迭代）
- 数据录入与批量导入（CSV/Excel）。
- 古建信息审核、更新日志。
- 用户反馈管理与数据统计（访问量、收藏量）。

## 4. 非功能需求
- **性能**：首次加载 < 5s；地图交互响应 < 200ms。
- **兼容性**：支持主流桌面浏览器与移动端响应式布局。
- **可维护性**：前端组件化、模块化，关键逻辑具备单元测试。
- **安全**：接口需鉴权（Token/JWT），防止数据滥用；对公开API请求限流。
- **可扩展性**：支持后续接入三方数据源（如文博系统）。

## 5. 数据需求
- 古建基础表结构建议字段：`id`、`name`、`alias`、`dynasty`、`type`、`province`、`city`、`county`、`latitude`、`longitude`、`level`、`open_status`、`ticket`、`opening_hours`、`transportation`、`description`、`features`、`images[]`、`related_links[]`。
- 用户收藏表：`user_id`、`heritage_id`、`note`、`created_at`。
- 数据来源：山西省文物局公开资料、旅游局数据、开放地图数据。

## 6. 项目里程碑（建议）
1. **需求梳理与原型设计**（第1周）：完成PRD、信息架构、低保真原型。
2. **基础架构搭建**（第2周）：完成项目脚手架、地图底座、UI框架配置。
3. **核心功能开发**（第3-4周）：实现地图展示、检索筛选、详情页、收藏夹。
4. **数据接入与优化**（第5周）：导入初始古建数据、性能优化、SEO。
5. **测试与上线**（第6周）：功能测试、部署、监控配置。

## 7. 验收标准
- 核心功能覆盖 > 95%，关键路径无高危Bug。
- 符合设计规范，UI一致性良好。
- 项目文档、部署脚本、监控预警均完善。
